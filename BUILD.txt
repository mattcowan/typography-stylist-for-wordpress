===============================================================================
BUILD AND SOURCE - Typography Stylist
===============================================================================

This file tells you what the plugin zip contains, which files are compiled,
the source files of each compiled file, and how to build them again.

The zip contains the source file of each compiled file. The zip does not
contain the build configuration (for example .babelrc and package-lock.json).
To build the plugin, get the source from the public repository:

   https://github.com/mattcowan/typography-stylist-for-wordpress

Each release since 2.1.2 has a tag in the repository, for example v2.3.6.
The tags of 2.2.0 to 2.2.3 have no "v", for example 2.2.3.

===============================================================================
1. WHAT THE ZIP CONTAINS
===============================================================================

   The zip contains each source file that section 3 names.

   assets/js/admin-export.js
   assets/js/editor-font-kits.js
   blocks/typography-stylist/block.json
   blocks/typography-stylist/style.css
   blocks/typography-stylist/editor.css

   variable-fonts/assets/js/ and variable-fonts/assets/css/
   paragraph-styles/assets/js/ and paragraph-styles/assets/css/

   These files are hand-written. They are the source, and no build step
   changes them.

THIRD-PARTY LIBRARIES (section 4)
   glyphs-panel/assets/js/vendor/opentype.min.js
   glyphs-panel/assets/js/vendor/wawoff2/decompress_binding.js

OTHER FILES
   assets/images/icons/ (SVG icons)

   readme.txt, changelog.txt, BUILD.txt (this file), package.json

NOT IN THE ZIP
   The tests, the build configuration, the developer documentation and
   the development tools. The .distignore file in the repository lists

===============================================================================
2. HOW TO BUILD
===============================================================================

You need Node.js 22.22.2 or later in the 22 line, 24.15.0 or later in the
24 line, or 26 or later. @wordpress/scripts requires one of these versions.
npm comes with Node.js.

1. Get the source:

      git clone https://github.com/mattcowan/typography-stylist-for-wordpress.git
      cd typography-stylist-for-wordpress

   To build one release, check out its tag, for example:

      git checkout v2.3.6

2. Install the build tools at the versions in package-lock.json:

      npm ci

3. Build all compiled files:

      npm run build

   This command runs build:block, build:js and build:css (section 3).

4. Make the plugin zip (optional):

      npm run package

   This command runs the build again, then writes typography-stylist.zip.
   The .distignore file decides which files go into the zip.

The compiled files are not in the repository (git ignores them). A copy of
the repository works in WordPress only after step 3.

To run the tests, read TESTING.md in the repository.

Bundled modules: the Glyphs Panel, Variable Fonts and Paragraph Styles
modules have no build step. Their scripts are hand-written ES5 and their
styles are plain CSS. WordPress loads these files as written. The one
exception is the third-party libraries of the Glyphs Panel (section 4).

===============================================================================
4. THIRD-PARTY LIBRARIES
===============================================================================

The Glyphs Panel reads font files in the browser with two open-source
libraries. They are the upstream distribution files, not changed and not
built by this plugin.

opentype.js v1.3.4 (MIT License): reads TTF, OTF and WOFF font files.
   File:   glyphs-panel/assets/js/vendor/opentype.min.js
   Source: https://github.com/opentypejs/opentype.js
           (tag 1.3.4; the repository at that tag has the unminified
           dist/opentype.js)

wawoff2 2.0.1 (MIT License): decompresses WOFF2 font files. It is a WebAssembly
build of Google's woff2, in one file with the WebAssembly code embedded.
   File:   glyphs-panel/assets/js/vendor/wawoff2/decompress_binding.js
   Source: https://github.com/fontello/wawoff2

To update a library, replace its file with the file from the upstream
release.
